COMO ENVIAR PELO SITE DO GITHUB (SEM TERMINAL)
1. Abra github.com/ccidesenvolvimento-ui/excelencia-5-estrelas-2027
2. Em Code, no seletor da branch, crie feat/interface-unificada-v06 a partir da main.
3. Extraia o ZIP desta atualizacao no Windows.
4. Na branch nova, Add file > Upload files.
5. Arraste o CONTEUDO EXTRAIDO (pastas src, scripts, docs e arquivos package.json, README.md etc.) para a raiz. Nao envie a pasta externa inteira, nem o ZIP.
6. Confira os caminhos e as substituicoes. Em especial: src/app/ranking/page.tsx, src/app/configuracoes/page.tsx, src/app/modulos.css e src/components/Navegacao.tsx.
7. Commit changes na branch v06. Crie Pull Request da v06 para main.
8. Confira Actions (typecheck, regras, interface, build e publicacao) antes do merge. Se falhar, nao faça merge: copie o erro para analisarmos.
9. Quando aprovado, Merge pull request. O site demonstrativo sera atualizado automaticamente.
